# Task 21: U5: Frontend: สร้าง UI หน้า Dashboard สำหรับให้เจ้าของร้านเข้ามาจัดการระบบ

## ข้อมูลงาน (Task Details)
- **รหัสงานบน Trello**: `Task21:U5:Frontend: สร้างUI หน้า Dashboard สำหรับให้เจ้าของร้านเข้ามาจัดการระบบ`
- **User Story**: `U5: เปลี่ยนสถานะร้าน` (และรองรับฟังก์ชันเจ้าของร้านที่กำหนดในโจทย์)
- **ผู้รับผิดชอบ**: UI/UX Designer & Frontend Developer
- **เป้าหมาย**: ออกแบบและพัฒนาหน้าจอ Dashboard ฝั่งเจ้าของร้าน (แม่ค้า) แบบ Mobile-First เพื่ออำนวยความสะดวกให้แม่ค้าสามารถจัดการร้านอาหารผ่านสมาร์ตโฟนได้อย่างคล่องตัว รวดเร็ว และเข้าใจง่าย

---

## ฟังก์ชันหลักในหน้า Dashboard (Key Features)

1. **Header & ข้อมูลร้าน**:
   - แสดงชื่อร้าน, สังกัดโรงอาหาร (กรีนแคนทีน / คณะวิทย์) และหมายเลขล็อค
   - ปุ่มสลับโหมด / ปุ่มออกจากระบบ (Logout)
2. **ระบบควบคุมสถานะร้าน (Real-time Store Status)**:
   - ปุ่ม Toggle ขนาดใหญ่เพื่อสลับสถานะ "เปิดให้บริการ (OPEN)" หรือ "ปิดร้าน (CLOSED)" ทันที
   - แถบตั้งเวลาเปิด-ปิดอัตโนมัติ (เช่น 07:30 - 16:00) แม่ค้าสามารถกดแก้ไขเวลาได้โดยตรง
3. **ระบบจัดการเมนูและแจ้ง "เมนูหมด" (Out of Stock / Sold Out Management)**:
   - รายการเมนูทั้งหมดของร้าน พร้อมราคา
   - สวิตช์ปุ่มลัดสลับสถานะ **"ของหมด" (Sold Out)** หรือ **"พร้อมขาย" (Available)** เพียงแตะ 1 ครั้ง
   - เมื่อแม่ค้ากดของหมด ลูกค้าที่เข้ามาดูจะเห็นป้ายกำกับ "ของหมด" ทันที ไม่ต้องสั่งเก้อ
4. **ฟอร์มเพิ่มเมนูอาหารใหม่ (Add Menu Item)**:
   - สามารถระบุชื่ออาหาร, ราคา และหมวดหมู่อาหารได้ทันที

## มาตรฐาน UI/UX ตามคำแนะนำของ ui-ux-pro-max
- **Touch Targets**: ปุ่มทุกปุ่มและ Toggle มีขนาดพื้นที่สัมผัสไม่ต่ำกว่า 44x44px (สะดวกต่อการกดของแม่ค้าขณะทำอาหาร)
- **Visual Feedback**: มีสีบอกสถานะชัดเจน (สีเขียวมรกต = เปิดร้าน/พร้อมขาย, สีส้มอำพัน = ของหมด, สีแดงกุหลาบ = ปิดร้าน)
- **Accessibility & Contrast**: อัตราส่วนคอนทราสต์ตัวอักษรต่อพื้นหลังเกิน 4.5:1 ตามเกณฑ์ WCAG 2.1 AA
