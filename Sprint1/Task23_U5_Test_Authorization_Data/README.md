# Task 23: U5: ทดสอบสิทธิ์การเข้าถึง และทดสอบความถูกต้องของข้อมูลในฐานข้อมูล

## ข้อมูลงาน (Task Details)
- **รหัสงานบน Trello**: `Task23:U5:ทดสอบสิทธิ์การเข้าถึง และทดสอบความถูกต้องของข้อมูลในฐานข้อมูล`
- **User Story**: `U5: เปลี่ยนสถานะร้าน`
- **ผู้รับผิดชอบ**: Security & QA Engineer
- **เป้าหมาย**: ทดสอบการจำกัดสิทธิ์การเข้าถึง (Authorization Boundary / RBAC) เพื่อรับประกันว่า:
  1. มีการตรวจสอบ Token ทุกครั้งที่มีการแก้ไขข้อมูลร้านหรือเปลี่ยนสถานะ
  2. เจ้าของร้าน A ไม่สามารถเปลี่ยนสถานะหรือแก้ไขร้าน B ได้ (403 Forbidden หรือ 401 Unauthorized)
  3. ตรวจสอบความถูกต้องของข้อมูล (Data Integrity) ในฐานข้อมูลหลังจากการสลับสถานะเปิด/ปิด หรือปรับปรุงข้อมูล
