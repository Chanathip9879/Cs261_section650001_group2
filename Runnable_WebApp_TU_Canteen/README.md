# TU Canteen Mobile Web Application (CS261 Sprint 1)
## โครงการเว็บแอปพลิเคชันตรวจสอบสถานะร้านอาหาร โรงอาหาร มหาวิทยาลัยธรรมศาสตร์ ศูนย์รังสิต

ระบบเว็บแอปพลิเคชัน Mobile-First สำหรับนักศึกษาและบุคลากร มธ.รังสิต เพื่อตรวจสอบสถานะร้านอาหารในโรงอาหารแบบทันท่วงที รู้ทันทีว่าร้านไหนเปิดหรือปิด และเมนูใดหมดแล้วบ้าง พร้อมระบบหลังบ้านสำหรับเจ้าของร้าน (แม่ค้า) และผู้ดูแลระบบ (แอดมิน)

---

## จุดเด่นของระบบตามความต้องการของโจทย์
1. **ออกแบบสำหรับมือถือเป็นหลัก (Mobile-First UI)** ตามแนวทาง `ui-ux-pro-max`:
   - การจัดวางองค์ประกอบแบบ Mobile Shell รองรับการใช้งานด้วยนิ้วโป้งเดียว (One-thumb interaction)
   - ขนาดปุ่มสัมผัส (Touch Targets) ไม่ต่ำกว่า 44x44px
2. **ขอบเขต 2 โรงอาหารหลักของ มธ.รังสิต**:
   - 🌿 **โรงอาหารกรีนแคนทีน (Green Canteen)**
   - 🔬 **โรงอาหารคณะวิทยาศาสตร์และเทคโนโลยี (Science Faculty Canteen)**
3. **ระบบค้นหาและตัวกรองที่ชาญฉลาด (Search & Filters)**:
   - ค้นหาได้ทั้ง **"ชื่อร้านอาหาร"** และ **"ชื่อเมนูอาหาร"** (เช่น พิมพ์ `กะเพรา` จะขึ้นร้านที่มีเมนูกะเพราทันที)
   - กรองตามโรงอาหาร (กรีนแคนทีน / คณะวิทย์)
   - กรองตามหมวดหมู่อาหาร (ข้าวแกง, ก๋วยเตี๋ยว, อาหารตามสั่ง, ข้าวมันไก่, เครื่องดื่ม)
   - กรองเฉพาะร้านที่เปิดให้บริการอยู่
4. **ความรู้สึกแบบ Grab Food (Real-time & Clear Status)**:
   - ร้านที่เปิด: แสดงสถานะสีเขียวมรกตพร้อม Pulse Animation
   - ร้านที่ปิด: แสดงสถานะสีแดง และการ์ดร้านจะปรับโทนสีลง (Grayscale Overlay) ชัดเจนเมื่อรีเฟรช
   - เมนูที่หมด: แสดงป้ายเตือนสีส้ม **[หมดแล้ววันนี้]** ชัดเจนที่รายการอาหาร
5. **ฝั่งผู้ใช้งาน (Students / Users)**:
   - **ไม่ต้องล็อกอิน (No Login Required)** เข้าใช้งานได้ทันที
   - สามารถเขียนรีวิวและให้คะแนนดาวร้านอาหารได้ทันทีโดยไม่ต้องมีเงื่อนไขผูกมัด
6. **ฝั่งเจ้าของร้าน (Merchants / แม่ค้า)**:
   - เข้าสู่ระบบด้วย **เบอร์โทรศัพท์ (10 หลัก) + PIN (4-6 หลัก)** รวดเร็ว ปลอดภัย และไม่มีค่าบริการ SMS
   - สวิตช์ Toggle ขนาดใหญ่ แตะสลับสถานะ "เปิดร้าน / ปิดร้าน" ทันที
   - กำหนดเวลาเปิด-ปิดร้าน (Operating Hours)
   - ปุ่มลัดสลับสถานะเมนูอาหาร **"แจ้งของหมด (Sold Out)"** หรือ **"พร้อมขาย"**
   - ฟอร์มเพิ่มเมนูอาหารใหม่ของร้าน
7. **ฝั่งผู้ดูแลระบบ (Admin)**:
   - สามารถเพิ่มร้านอาหารใหม่เข้าสู่โรงอาหารกรีนแคนทีน หรือ คณะวิทย์ ได้ทันที

## วิธีการติดตั้งและสั่งรันระบบ (How to Run)

### วิธีที่ 1: รันด้วย Node.js (เร็วที่สุด แนะนำสำหรับการทดสอบ)
1. เปิด Terminal ในโฟลเดอร์นี้:
   ```bash
   cd Sprint1/Runnable_WebApp_TU_Canteen
   ```
2. ติดตั้ง Dependencies และเริ่มรัน:
   ```bash
   npm install
   npm start
   ```
3. เปิดเบราว์เซอร์ไปที่:
   ```
   http://localhost:3000
   ```
4. เพื่อประสบการณ์การใช้งานที่ดีที่สุด ให้เปิดโหมด Mobile Device (กด `F12` ใน Google Chrome แล้วกด `Ctrl + Shift + M`)

---

### วิธีที่ 2: รันด้วย Docker Compose (สำหรับรันในห้อง Lab ตามเกณฑ์อาจารย์)
```bash
docker compose up -d --build
```
ระบบจะสร้าง Container และเปิดให้บริการที่ `http://localhost:3000` ทันที

## รายการ REST API Endpoints

- `GET /api/restaurants/search?q=...&canteen=...&category=...&status=...`: ค้นหาร้านอาหาร
- `GET /api/restaurants/:id`: ข้อมูลร้านอาหาร รายการเมนู และรีวิว
- `PATCH /api/restaurants/:id/status`: สลับสถานะเปิด/ปิดร้าน (Body: `{"status": "OPEN"|"CLOSED"}`)
- `PATCH /api/restaurants/:id/hours`: แก้ไขเวลาเปิด-ปิดร้าน
- `PATCH /api/products/:id/soldout`: สลับสถานะเมนูอาหารว่าหมดหรือไม่
- `POST /api/restaurants/:id/products`: เพิ่มเมนูอาหารใหม่
- `POST /api/restaurants/:id/reviews`: บันทึกรีวิว (ไม่ต้องล็อกอิน)
- `POST /api/auth/owner/login`: เข้าสู่ระบบแม่ค้าด้วย Phone + PIN
- `GET /api/auth/me`: ตรวจสอบความถูกต้องของ Token
- `POST /api/admin/restaurants`: แอดมินเพิ่มร้านอาหารใหม่
