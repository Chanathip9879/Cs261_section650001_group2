# รายงานการประเมินความปลอดภัยระบบยืนยันตัวตน (Authentication Security Report)

## สรุปผลการประเมินตามมาตรฐาน OWASP Top 10
ระบบ Authentication ของเจ้าของร้าน (แม่ค้า) ได้รับการออกแบบให้สอดคล้องกับข้อกำหนดระบบเว็บที่ปลอดภัย:

1. **A07:2021 Identification and Authentication Failures**:
   - ป้องกัน Brute Force Attack ได้สมบูรณ์ โดยล็อกบัญชีเมื่อมีความพยายามเข้าสู่ระบบผิดเกิน 5 ครั้ง
   - รหัสผ่าน PIN ถูกแฮชด้วย PBKDF2 with HMAC-SHA256 จำนวน 120,000 รอบ ไม่มีการจัดเก็บรหัสผ่านแบบข้อความธรรมดา
2. **Timing Attack Protection**:
   - มีการใช้ Dummy Hash ในกรณีที่ไม่พบเบอร์โทรศัพท์ เพื่อให้เวลาในการคำนวณ Hash เท่ากัน ป้องกันผู้ไม่หวังดีใช้เวลาตอบสนองมาคาดเดาข้อมูล
3. **Session Management**:
   - Token มีอายุ 8 ชั่วโมง และมี Endpoint `/api/auth/logout` เพื่อเพิกถอน Token ทันทีเมื่อเลิกใช้งาน
