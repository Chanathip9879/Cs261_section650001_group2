## เหตุผลการยกเลิกระบบพิกัด GPS แผนที่ (Rationale)
1. **ข้อจำกัดด้านงบประมาณและค่าใช้จ่าย (Cost Constraints)**: การใช้ Map SDK เช่น Google Maps Platform, Mapbox หรือ Geolocation API เชิงพาณิชย์ มีค่าธรรมเนียม API และค่าบริการตามจำนวนครั้งที่มีการเรียกใช้ (Per-request pricing) ซึ่งไม่สอดคล้องกับงบประมาณของโครงการนักศึกษา
2. **ความไม่เหมาะสมกับบริบทโรงอาหารในมหาวิทยาลัย (Context Fit)**: ร้านอาหารส่วนใหญ่ตั้งอยู่ในอาคารโรงอาหารเดียวกัน (เช่น โรงอาหารกรีนแคนทีน หรือ อาคารบรรยายรวมคณะวิทยาศาสตร์) การใช้พิกัดละติจูด/ลองจิจูดแบบดาวเทียมจะทำให้หมุดทับซ้อนกันในอาคารเดียว และไม่สามารถบอกได้ว่าร้านอยู่ล็อคไหนหรือชั้นใด

## โซลูชันทดแทนที่มีประสิทธิภาพกว่า (Approved Alternative)
ปรับเปลี่ยนมาใช้ **"ระบบระบุสังกัดโรงอาหารและหมายเลขล็อค/ห้องร้านอาหาร" (Canteen & Stall Location System)**:
- แบ่งโรงอาหารชัดเจน 2 แห่งใน มธ.รังสิต:
  1. **โรงอาหารกรีนแคนทีน (Green Canteen)**: ระบุเลขล็อค เช่น `ล็อค 3 กรีนแคนทีน`, `ล็อค 7 กรีนแคนทีน`
  2. **โรงอาหารคณะวิทยาศาสตร์ (Science Faculty Canteen)**: ระบุห้อง เช่น `ห้อง SC1 อาคารบรรยายรวมวิทย์`
- ฝั่ง Frontend: ทำ Canteen Filter Selector Chips แถบด้านบนให้เลือกสลับโรงอาหารได้ทันที พร้อม Location Badge สวยงาม แสดงตำแหน่งของร้านอย่างชัดเจน
- ช่วยประหยัดค่าใช้จ่าย 100% ตอบโจทย์การใช้งานของนักศึกษาจริง รวดเร็วกว่า ไม่ต้องโหลดแผนที่หนักเครื่อง
